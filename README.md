# NESCAFÉ Landing Page  

Este repositorio contiene el proyecto de **landing page para NESCAFÉ**, desarrollado como parte del curso de **Full Stack Design en EBAC**. El objetivo fue crear una interfaz moderna, optimizada y accesible, siguiendo buenas prácticas de desarrollo Front-End.

---

## 🚀 Características principales  
- **Diseño responsive** y mobile-first.  
- **Estilos escalables con SASS (arquitectura 7-1)** para un mantenimiento sencillo.  
- **Optimización de SEO y accesibilidad**:  
  - Etiquetas semánticas (`header`, `main`, `footer`, etc.).  
  - Uso correcto de `alt`, `aria-label` y roles.  
- **Interactividad con JavaScript Vanilla (ES6)**:  
  - Carrito de compras funcional.  
  - Menús y sliders dinámicos.  
- **Recursos multimedia optimizados** con `lazy-loading`.

---

## 🛠 Stack utilizado  

| Área | Tecnologías |
|-------|-------------|
| Maquetación | **HTML5 semántico** |
| Estilos | **SASS**, CSS3 |
| Scripts | **JavaScript Vanilla (ES6)** |
| Control de versiones | **Git + GitHub** |
